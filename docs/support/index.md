# Flipzy Support

Need help with Flipzy? We’re here to help.

## Contact
Email us at: **mehmetoztin@gmail.com**

Please include:
- your device model (e.g., iPhone 14)
- iOS version
- Flipzy app version
- what you tried and what happened
- screenshots or screen recordings (if possible)

## Common Topics

### 1) Purchases / Premium not unlocked
If you purchased Premium and it doesn’t unlock:
1. Make sure you’re signed into the same Apple ID used for the purchase.
2. Close and reopen the app.
3. Try “Restore Purchases” in the app (if available).
4. If it still doesn’t work, email us with your purchase date and a screenshot of the subscription screen.

### 2) App crashes or freezes
Email us with:
- what you were doing right before the issue
- the exact screen where it happens
- screenshots/video if you can

### 3) Content & quality issues
If a generated result looks wrong:
- share the input type (single photo / couple photo)
- which feature you used (Future Baby / Filter / Reveal)
- which template or style you selected

### 4) Delete my data
To request deletion of your data, email: **mehmetoztin@gmail.com**
Subject line: **Delete My Data**
